# GitQuack Agent Guide

GitQuack is a local Git learning assistant for students. This repository is currently only the initial TypeScript CLI scaffolding.

Use the skills in `.agents/skills/` for future work:

- `gitquack-product`: product direction, student audience, and scope boundaries.
- `gitquack-cli-development`: CLI implementation conventions.
- `gitquack-testing`: testing expectations for future GitQuack behavior.

Do not implement Git hooks, command interception, push interception, branch-name validation, telemetry, or network features unless a future task explicitly asks for them.
