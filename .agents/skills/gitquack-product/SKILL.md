# GitQuack Product Skill

Use this skill when shaping future GitQuack product behavior.

GitQuack is intended to help students build better Git habits from their own terminal. The product should feel local, lightweight, encouraging, and clear. It should explain Git concepts without shame, surprises, or hidden automation.

Future product work should:

- Prioritize student learning over enforcement.
- Prefer short, actionable guidance.
- Keep all behavior local unless explicitly designed otherwise.
- Avoid collecting telemetry or sending repository data over the network.
- Make potentially intrusive behavior opt-in and easy to understand.

Current status: only initial CLI scaffolding exists. Do not implement Git hooks, command interception, warnings, configuration logic, or GitQuack learning features as part of this scaffold.
